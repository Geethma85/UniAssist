# UniAssist three-minute demo

All university names and policies in this demo are fictional.

## Before starting
- Start Flask and Flutter.
- Prepare demo student and admin accounts.
- Keep fictional-university-guide.txt uploaded.
- Have temporary-delete-demo.txt ready locally.
- Check Gemini responds before presenting.

## 0:00–0:25 — Login
Log in with the student demo account.
Say: “UniAssist helps students with general study questions and
information from uploaded university documents.”

## 0:25–0:50 — General chat
Ask: “How can I plan revision for three exams next week?”
Show the practical study advice.

## 0:50–1:25 — Cited document answer
Start a new conversation.
Ask: “When does Example Horizon University's library open on weekdays?”
Show Monday–Friday, 08:30–18:00 and the filename citation.
Say: “This answer comes from our fictional demo guide.”

## 1:25–1:45 — Conversation history
Open History and reopen the library conversation.
Show that the question and answer were retained.

## 1:45–2:40 — Admin document management
Switch to the prepared admin account.
Open Manage documents and show the main guide.
Upload temporary-delete-demo.txt and show its list entry.
Delete only that temporary upload.
Refresh and confirm the main guide remains.

## 2:40–3:00 — Finish
Say: “The demo covers chat, document-based answers, saved history,
and admin document management. Gemini can temporarily be unavailable;
clearer error reporting and broader retrieval evaluation remain planned.”

## If Gemini is unavailable
Briefly retry once. If it still fails, show the saved conversation
and explicitly say it is a previous successful response.
